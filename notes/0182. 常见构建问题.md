## 1. 本节内容

- 了解 Vite 生产构建时的常见问题
- 掌握构建失败、依赖解析、动态导入、内存不足等问题的排查方法

## 2. 评价

- 构建问题通常比启动问题更难排查，需要仔细阅读错误堆栈

## 3. 构建失败

- 常见原因：
  - TypeScript 类型错误：先运行 `tsc --noEmit` 检查
  - 语法错误：检查错误信息中的文件和行号
  - 插件错误：禁用最近添加的插件排查
  - 依赖缺失：检查 `node_modules` 是否完整

## 4. 依赖无法解析

- 问题：`Failed to resolve import "xxx"`
- 常见原因：
  - 依赖未安装：`npm install xxx`
  - 路径别名未配置：检查 `resolve.alias` 和 `tsconfig.json` 的 `paths`
  - 包的 ESM 入口缺失：检查包的 `package.json` 的 `exports` 字段
  - Monorepo 中的包未链接：运行 `pnpm install`

## 5. 动态导入错误

- 问题：动态导入的模块无法解析
- 原因：`import()` 的路径必须是可静态分析的
- 解决：
  - 使用字面量路径：`import('./utils/foo.ts')`
  - 使用 `import.meta.glob` 替代动态路径

## 6. 大小写路径问题

- 问题：Windows/macOS 不区分大小写，但 Linux 区分
- 表现：本地构建正常，CI 构建失败
- 解决：确保文件路径的大小写与代码中的引用一致

## 7. 内存不足

- 问题：`JavaScript heap out of memory`
- 解决：
  - 增加 Node.js 内存限制：`NODE_OPTIONS=--max-old-space-size=4096 vite build`
  - 减少并行构建任务
  - 拆分大型 chunk
  - 检查是否有内存泄漏的插件
