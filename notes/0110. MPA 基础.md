## 1. 本节内容

- 了解 SPA 和 MPA 的区别
- 掌握 Vite MPA 的目录设计和多入口 HTML 配置

## 2. 评价

- MPA 适合多个独立页面的场景，每个页面有独立的入口和路由
- 大部分现代前端项目使用 SPA，MPA 在特定场景下有其优势

## 3. 单页面应用与多页面应用区别

| 维度     | SPA                      | MPA                        |
| -------- | ------------------------ | -------------------------- |
| 页面加载 | 一次加载，路由切换不刷新 | 每个页面独立加载，切换刷新 |
| URL      | 由前端路由控制           | 每个页面有独立的 URL       |
| SEO      | 需要 SSR 支持            | 天然友好                   |
| 首屏速度 | 需要加载整个应用         | 只加载当前页面             |
| 用户体验 | 流畅，无刷新             | 有页面刷新感               |
| 适用场景 | 后台管理、SPA 应用       | 官网、活动页、多业务线     |

## 4. Vite MPA 目录设计

- 推荐的目录结构：

```
project/
├── index.html              # 主页面入口
├── admin/
│   └── index.html          # 管理后台入口
├── login.html              # 登录页入口
├── src/
│   ├── main.ts             # 主页面逻辑
│   ├── admin/
│   │   └── main.ts         # 管理后台逻辑
│   ├── login/
│   │   └── main.ts         # 登录页逻辑
│   └── shared/             # 共享代码
│       ├── utils.ts
│       └── styles/
├── vite.config.ts
└── package.json
```

## 5. 多入口 HTML

- 每个 HTML 文件是独立的页面入口，可以有各自的 JS、CSS 和 meta 信息
- 构建时每个入口生成独立的 chunk，共享模块自动提取
- 配置方式见 0107 节「多页面 HTML」
