## 1. 本节内容

- 了解适合 Vite 初学者的入门项目
- 掌握 Vanilla、Vue、React 的基础项目搭建

## 2. 评价

- 入门项目应该简单明了，专注于理解 Vite 的核心概念
- 建议先从 Vanilla 项目开始，理解 Vite 本身，再学习框架集成

## 3. Vite + Vanilla + TypeScript Todo

- 最简单的 Vite 项目，不使用任何框架
- 学习目标：
  - Vite 的项目结构
  - TypeScript 配置
  - CSS Modules
  - 静态资源导入
- 功能：添加、删除、标记完成的 Todo 项

## 4. Vite + Vue 计数器

- 使用 Vue 3 + Vite 搭建简单的计数器
- 学习目标：
  - Vue SFC 的编译
  - `<script setup>` 语法
  - HMR 的体验
  - Vue 插件配置

## 5. Vite + React 组件 Demo

- 使用 React + Vite 搭建组件演示
- 学习目标：
  - JSX/TSX 配置
  - React Fast Refresh
  - SWC 编译器
  - CSS Modules 在 React 中的使用
