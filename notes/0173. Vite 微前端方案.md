## 1. 本节内容

- 了解 Vite 生态中的微前端方案
- 掌握 qiankun、micro-app、Module Federation 等方案的特点

## 2. 评价

- 没有完美的微前端方案，选择时应根据项目需求和团队情况决定
- Module Federation 是 Vite 生态中最有前景的方案

## 3. qiankun

- 蚂蚁金服开源的微前端框架，基于 single-spa
- 特点：
  - JS 沙箱隔离（快照沙箱、Proxy 沙箱）
  - CSS 隔离（Shadow DOM 或 Scoped）
  - 预加载
  - 通信机制
- Vite 子应用需要使用 `vite-plugin-qiankun` 适配

## 4. micro-app

- 京东开源的微前端框架，基于 Web Component
- 特点：
  - 使用 Web Component 的 Custom Element 实现
  - 接入简单，类似 iframe 的使用方式
  - 支持 Vite 子应用
  - 性能好，沙箱隔离完善

```html
<micro-app name="app1" url="http://localhost:3001/"></micro-app>
```

## 5. Module Federation

- Webpack 5 引入的模块联邦机制，Vite 通过 `@originjs/vite-plugin-federation` 支持
- 特点：
  - 运行时共享模块
  - 真正的代码级别共享（不是 iframe）
  - 支持双向依赖
- 详见 0174 节

## 6. Web Components

- 使用 Web Components 实现微前端：
  - 每个子应用打包为 Web Component
  - 主应用通过 Custom Element 加载子应用
  - 天然的 Shadow DOM 样式隔离
- 适合简单的微前端场景

## 7. iframe

- 最简单的微前端方案：使用 iframe 嵌入子应用
- 优点：天然隔离，接入成本最低
- 缺点：
  - 通信困难（postMessage）
  - 体验差（刷新、前进后退）
  - 性能开销大
  - URL 不同步
