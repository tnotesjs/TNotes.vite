## 1. 本节内容

- 了解 Vite 项目在运行时的常见问题
- 掌握页面空白、资源 404、路由刷新、环境变量、CSS 丢失等问题的排查方法

## 2. 评价

- 运行时问题通常与部署配置有关，而非 Vite 本身的问题

## 3. 页面空白

- 常见原因：
  - JavaScript 报错导致应用无法启动：打开浏览器控制台查看错误
  - `base` 配置错误：资源路径不正确
  - 路由配置错误：没有匹配到任何路由
  - CSP（Content Security Policy）阻止了脚本执行

## 4. 资源 404

- 常见原因：
  - `base` 配置与部署路径不匹配
  - 静态资源未正确部署到服务器
  - CDN 路径配置错误
- 排查：检查浏览器 Network 面板中 404 资源的实际请求路径

## 5. 路由刷新 404

- 使用 BrowserRouter 时刷新页面出现 404
- 原因：服务器没有配置 SPA fallback
- 解决：配置 Nginx `try_files $uri $uri/ /index.html`
- 详见 0160 节「SPA 部署」

## 6. 环境变量未生效

- 常见原因：
  - 变量名没有 `VITE_` 前缀
  - `.env` 文件放错了位置（应放在项目根目录）
  - 修改 `.env` 后没有重启开发服务器
  - 使用了错误的 `.env.[mode]` 文件
- 排查：在代码中 `console.log(import.meta.env)` 查看所有环境变量

## 7. CSS 丢失

- 常见原因：
  - CSS 文件路径错误
  - CSS 预处理器未安装（如 `sass`、`less`）
  - PostCSS 配置错误
  - CSS Modules 的类名不匹配
