## 1. 本节内容

- 了解微前端开发中的常见问题
- 掌握样式隔离、JS 沙箱、路由隔离等问题的解决方案

## 2. 评价

- 微前端的大部分问题源于多个独立应用在同一页面运行时的冲突
- 理解这些问题有助于选择合适的微前端方案

## 3. 样式隔离

- 多个子应用的 CSS 可能相互污染
- 解决方案：
  - Shadow DOM：天然的样式隔离，但有兼容性问题
  - CSS Modules：每个子应用使用独立的类名哈希
  - 命名空间：为每个子应用的 CSS 添加前缀
  - Scoped CSS（Vue）：自动添加作用域

## 4. JS 沙箱

- 子应用的全局变量可能污染主应用或其他子应用
- 解决方案：
  - Proxy 沙箱：通过 Proxy 代理 window 对象，隔离全局变量
  - 快照沙箱：激活子应用时保存 window 快照，卸载时恢复
  - iframe 沙箱：最彻底的隔离，但体验较差

## 5. 路由隔离

- 多个子应用的路由可能冲突
- 解决方案：
  - 为每个子应用设置路由前缀（如 `/app1/*`、`/app2/*`）
  - 主应用负责路由分发，子应用只处理自己的路由
  - 使用 hash 路由避免与主应用的 history 路由冲突

## 6. 公共依赖共享

- 多个子应用可能依赖相同的库（如 Vue、React），重复加载浪费资源
- 解决方案：
  - Module Federation：运行时共享依赖（推荐）
  - externals + CDN：将公共依赖通过 CDN 引入
  - 主应用提供：主应用加载依赖，子应用通过 externals 使用

## 7. 部署与版本管理

- 微前端的部署比单体应用复杂
- 需要考虑的问题：
  - 子应用的版本兼容性
  - 灰度发布和回滚
  - 子应用的健康检查
  - 配置中心管理子应用的 URL 映射
