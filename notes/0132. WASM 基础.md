## 1. 本节内容

- 了解 WebAssembly 的基本概念
- 掌握 WASM 的使用场景和 JS 通信方式

## 2. 评价

- WASM 适合需要极致性能的场景（如游戏引擎、音视频处理、加密算法）
- 大部分 Web 应用不需要 WASM，JavaScript 的性能已经足够

## 3. WebAssembly 是什么

- WebAssembly（WASM）是一种二进制指令格式，可以在浏览器中以接近原生的速度运行
- 特点：
  - 二进制格式，体积小、加载快
  - 接近原生的执行速度
  - 与 JavaScript 互操作
  - 支持多种语言编译（C/C++、Rust、Go、AssemblyScript）
- WASM 不是 JavaScript 的替代品，而是补充

## 4. WASM 使用场景

- 适合使用 WASM 的场景：
  - 游戏引擎和 3D 渲染
  - 音视频编解码
  - 图像处理和计算机视觉
  - 加密和压缩算法
  - CAD/CAE 等专业软件的 Web 版
- 不适合的场景：
  - 简单的 Web 应用（JS 足够）
  - 需要频繁操作 DOM 的任务（WASM 无法直接访问 DOM）

## 5. JS 与 WASM 通信

- WASM 模块通过 `imports` 和 `exports` 与 JavaScript 交互：

```ts
// 加载 WASM 模块
const response = await fetch('./module.wasm')
const { instance } = await WebAssembly.instantiateStreaming(response)

// 调用导出的函数
const result = instance.exports.add(1, 2)

// 访问共享内存
const memory = new Uint8Array(instance.exports.memory.buffer)
```

- 通信开销：JS 和 WASM 之间的调用有一定开销，应尽量减少频繁的小调用
