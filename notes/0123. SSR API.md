## 1. 本节内容

- 了解 Vite SSR 相关的核心 API
- 掌握 `createServer`、`ssrLoadModule`、`transformIndexHtml` 等 API 的用法

## 2. 评价

- 这些 API 是手动搭建 SSR 时的核心工具
- 使用 Nuxt/Next.js 时通常不需要直接调用这些 API

## 3. `createServer`

- 创建 Vite 开发服务器（支持 SSR 中间件模式）：

```ts
import { createServer } from 'vite'

const vite = await createServer({
  server: { middlewareMode: true },
  appType: 'custom',
})
```

- `middlewareMode: true`：不创建独立的 HTTP 服务器，返回中间件供 Express/Koa 使用

## 4. `ssrLoadModule`

- 在服务端加载模块（开发模式下直接加载源码）：

```ts
const { render } = await vite.ssrLoadModule('/src/entry-server.ts')
const html = await render(url)
```

- 优势：开发时无需构建，直接加载 TypeScript/Vue 源码
- 支持 HMR：文件变化后自动重新加载

## 5. `transformIndexHtml`

- 转换 `index.html`，注入渲染结果和资源引用：

```ts
const template = await vite.transformIndexHtml(
  url,
  fs.readFileSync('index.html', 'utf-8'),
)
const html = template.replace('<!--ssr-outlet-->', appHtml)
```

- 会自动处理环境变量替换和资源路径

## 6. `render`

- 应用的 SSR 渲染函数（由开发者实现）：

```ts
export async function render(url: string) {
  const app = createApp()
  const html = await renderToString(app)
  return html
}
```

- Vue 使用 `renderToString`，React 使用 `renderToString` 或 `renderToPipeableStream`

## 7. `createViteServer`

- `createServer` 的别名，功能相同
- 在某些文档和示例中可能使用此名称
