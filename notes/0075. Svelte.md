## 1. 本节内容

- 了解 Svelte 与 Vite 的集成方式
- 掌握 Svelte 项目的基本创建和使用
- 理解 Svelte 与 SvelteKit 的关系

## 2. 评价

- Svelte 是 Vite 原生支持的一流框架，集成体验优秀
- Svelte 5（Runes）引入了新的响应式模型，与 Vite 的集成更加紧密
- 如果需要完整的应用框架（路由、SSR 等），应使用 SvelteKit

## 3. Svelte + Vite

- 创建 Svelte 项目：

```bash
npm create vite@latest my-svelte-app -- --template svelte

# TypeScript 版本
npm create vite@latest my-svelte-app -- --template svelte-ts
```

- Svelte 在 Vite 中的工作方式：
  - `@sveltejs/vite-plugin-svelte` 插件处理 `.svelte` 文件的编译
  - Svelte 是编译时框架：组件在构建时被编译为高效的原生 JS 操作
  - 运行时开销极小，产物体积小
- Vite 是 Svelte 和 SvelteKit 的官方推荐构建工具

## 4. SvelteKit 关系

- Svelte 是 UI 框架（类似 Vue/React），只负责组件渲染
- SvelteKit 是基于 Svelte 的全栈应用框架（类似 Next.js/Nuxt）
- SvelteKit 提供：
  - 文件系统路由
  - SSR / SSG
  - API 路由（Server Routes）
  - 数据加载（Load Functions）
  - 适配器系统（部署到 Node.js、Vercel、Cloudflare 等）
- 创建 SvelteKit 项目：

```bash
npm create svelte@latest my-app
```

- SvelteKit 底层使用 Vite 作为构建工具，所有 Vite 插件和配置都可以直接使用
- 新项目推荐直接使用 SvelteKit，而非纯 Svelte + Vite
