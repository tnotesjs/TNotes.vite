## 1. 本节内容

- 了解 Preact 与 Vite 的集成方式
- 掌握 React 兼容别名的配置
- 理解 Preact 的适用场景和与 React 的差异

## 2. 评价

- Preact 是 React 的轻量替代品（约 3KB），API 高度兼容
- 适合对包体积敏感的项目（如嵌入式组件、移动端 H5）
- 与 Vite 集成无需额外插件，通过别名即可实现

## 3. Preact + Vite

- 创建 Preact 项目：

```bash
npm create vite@latest my-app -- --template preact

# TypeScript 版本
npm create vite@latest my-app -- --template preact-ts
```

- Preact 使用 `@preact/preset-vite` 插件：

```ts
// vite.config.ts
import preact from '@preact/preset-vite'

export default defineConfig({
  plugins: [preact()],
})
```

- Preact 的特点：
  - 体积小：约 3KB gzipped（React 约 42KB）
  - API 兼容：支持 Hooks、Context、Fragments 等 React 核心 API
  - 性能优秀：虚拟 DOM 实现更轻量
  - 缺点：不支持 React 18 的 Concurrent Features、Suspense for Data Fetching 等新特性

## 4. React 兼容别名

- Preact 通过别名实现与 React 的兼容：

```ts
// vite.config.ts
import { defineConfig } from 'vite'

export default defineConfig({
  resolve: {
    alias: {
      react: 'preact/compat',
      'react-dom': 'preact/compat',
      'react-dom/test-utils': 'preact/test-utils',
      'react/jsx-runtime': 'preact/jsx-runtime',
    },
  },
})
```

- 效果：项目中 `import React from 'react'` 实际导入的是 `preact/compat`
- 大部分 React 库（如 React Router、Redux）可以无缝使用
- 但某些依赖 React 内部 API 的库可能不兼容
- `@preact/preset-vite` 插件已内置此别名配置，无需手动设置
