## 1. 本节内容

- 了解 Vue 和 React 组件库的打包方式
- 掌握样式打包和按需引入的配置
- 理解组件库的 Tree Shaking 优化

## 2. 评价

- 组件库打包比普通库更复杂，需要同时处理 JS、CSS 和类型声明
- 按需引入是组件库的核心优化点，可以大幅减少消费者的打包体积

## 3. Vue 组件库

- 使用 Vite 库模式打包 Vue 组件库：

```ts
export default defineConfig({
  build: {
    lib: {
      entry: 'src/index.ts',
      formats: ['es', 'cjs'],
      fileName: (format) => `index.${format}.js`,
    },
    rollupOptions: {
      external: ['vue'],
      output: {
        globals: { vue: 'Vue' },
      },
    },
  },
})
```

- 入口文件导出所有组件：

```ts
// src/index.ts
export { default as Button } from './components/Button.vue'
export { default as Input } from './components/Input.vue'
```

## 4. React 组件库

- 类似 Vue 组件库，但需要处理 JSX：

```ts
export default defineConfig({
  plugins: [react()],
  build: {
    lib: {
      entry: 'src/index.ts',
      formats: ['es', 'cjs'],
      fileName: (format) => `index.${format}.js`,
    },
    rollupOptions: {
      external: ['react', 'react-dom'],
    },
  },
})
```

## 5. 样式打包

- 组件库的样式处理方式：
  - 打包到 JS 中：通过 `import './style.css'` 内联（简单但无法按需）
  - 单独输出 CSS 文件：Vite 默认行为，提取为独立的 `style.css`
  - 按组件输出 CSS：每个组件单独输出 CSS 文件（按需引入的基础）

## 6. 按需引入

- 通过 `exports` 字段实现按需引入：

```json
{
  "exports": {
    ".": {
      "import": "./dist/index.es.js",
      "require": "./dist/index.cjs.js"
    },
    "./button": {
      "import": "./dist/components/Button.es.js",
      "require": "./dist/components/Button.cjs.js"
    },
    "./style": "./dist/style.css"
  }
}
```

- 消费者可以只引入需要的组件：`import { Button } from 'my-lib/button'`

## 7. Tree Shaking

- 确保组件库支持 Tree Shaking：
  - 使用 ESM 格式
  - 在 `package.json` 中设置 `"sideEffects": ["*.css"]`
  - 避免在入口文件中有副作用代码
  - 每个组件作为独立模块导出
