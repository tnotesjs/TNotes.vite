## 1. 本节内容

- 了解 Vite 项目中进行类型检查的方式
- 掌握 `vue-tsc`、`tsc --noEmit`、`vite-plugin-checker` 等工具的使用
- 理解 CI 中类型检查的最佳实践

## 2. 评价

- 类型检查是保障代码质量的重要环节，不应跳过
- 推荐在开发时使用 IDE 检查 + `vite-plugin-checker`，在 CI 中使用 `tsc --noEmit`

## 3. `vue-tsc`

- Vue 项目的类型检查工具，可以检查 `.vue` 单文件组件中的 TypeScript 代码
- 安装：`npm install -D vue-tsc`
- 使用：

```bash
# 只检查不输出
vue-tsc --noEmit

# 在 build 脚本中
vue-tsc --noEmit && vite build
```

- 为什么需要 `vue-tsc` 而不是 `tsc`？
  - `tsc` 无法识别 `.vue` 文件的类型（模板、script setup 等）
  - `vue-tsc` 使用 Vue 的语言服务来解析 `.vue` 文件
- `vue-tsc` 的版本应与 `vue` 版本匹配（通常由 Vue 模板自动管理）

## 4. `tsc --noEmit`

- React / 通用项目的类型检查方式
- `--noEmit` 参数表示只检查类型，不输出编译产物

```bash
# 基本用法
tsc --noEmit

# 使用项目引用（Monorepo）
tsc -b --noEmit
```

- 在 `package.json` 中配置：

```json
{
  "scripts": {
    "type-check": "tsc --noEmit",
    "build": "tsc --noEmit && vite build"
  }
}
```

- `-b`（`--build`）模式适用于 Monorepo，可以检查多个子包的类型依赖关系

## 5. `vite-plugin-checker`

- 在开发时在浏览器中显示类型错误的 Vite 插件
- 安装：`npm install -D vite-plugin-checker`
- 配置：

```ts
// vite.config.ts
import checker from 'vite-plugin-checker'

export default defineConfig({
  plugins: [
    vue(),
    checker({
      typescript: true, // 启用 TypeScript 检查
      // Vue 项目
      vueTsc: true,
      // 还可以启用 ESLint 检查
      eslint: {
        lintCommand: 'eslint "./src/**/*.{ts,tsx}"',
      },
    }),
  ],
})
```

- 效果：开发时类型错误会以覆盖层的形式显示在浏览器中（类似编译错误）
- 优势：无需在终端切换窗口查看类型错误，开发体验更好
- 注意：类型检查在后台运行，可能略微影响开发服务器的启动速度

## 6. CI 中的类型检查

- 在 CI/CD 流水线中将类型检查作为独立的步骤：

```yaml
# GitHub Actions 示例
jobs:
  type-check:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: 20
      - run: pnpm install
      - run: pnpm type-check # vue-tsc --noEmit 或 tsc --noEmit

  build:
    needs: type-check
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
      - run: pnpm install
      - run: pnpm build
```

- 最佳实践：
  - 类型检查失败时阻止构建和部署
  - 类型检查和 lint 检查可以并行运行
  - 将 `type-check` 脚本与 `build` 脚本分离，便于独立运行和重试
