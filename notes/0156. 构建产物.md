## 1. 本节内容

- 了解 Vite 构建产物的目录结构
- 理解 HTML、JS Chunk、CSS、Assets 等产物的作用

## 2. 评价

- 理解构建产物的结构有助于部署和问题排查

## 3. `dist`

- 默认的构建输出目录，可通过 `build.outDir` 修改
- 包含完整的可部署产物，直接将此目录部署到静态服务器即可

## 4. HTML

- `index.html` 位于 `dist/` 根目录
- 构建后自动注入了 JS 和 CSS 的引用路径（带内容哈希）
- HTML 文件本身不带哈希，便于服务器直接返回

## 5. JS Chunk

- 存放在 `dist/assets/js/` 目录
- 包含：
  - 入口 chunk（`index-[hash].js`）
  - 动态 chunk（路由懒加载等）
  - 共享 chunk（公共模块）
  - Vendor chunk（第三方依赖）
- 文件名带内容哈希，利于长期缓存

## 6. CSS

- 存放在 `dist/assets/css/` 目录
- Vite 自动提取 CSS 为独立文件
- 支持 CSS 代码分割（按路由/组件拆分）

## 7. Assets

- 静态资源（图片、字体等）存放在 `dist/assets/` 目录
- 小于 `assetsInlineLimit` 的资源已被 Base64 内联到 JS/CSS 中
- 大资源作为独立文件输出，文件名带内容哈希

## 8. Source Map

- 如果开启了 `build.sourcemap`，每个 JS/CSS 文件会生成对应的 `.map` 文件
- Source Map 文件不应部署到公开服务器（除非使用 `hidden` 模式）
- 通常上传到错误监控平台用于错误定位
