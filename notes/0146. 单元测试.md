## 1. 本节内容

- 了解 Vite 项目中的单元测试方案
- 掌握 Vitest 的基本配置和使用
- 理解 Jest 与 Vitest 的差异

## 2. 评价

- Vitest 是 Vite 生态的首选测试框架，与 Vite 深度集成
- 新项目推荐 Vitest，已使用 Jest 的项目可以平滑迁移

## 3. Vitest

- 由 Vite 团队开发的测试框架，与 Vite 共享配置和插件系统

```bash
npm install -D vitest
```

```ts
// vite.config.ts
import { defineConfig } from 'vitest/config'

export default defineConfig({
  test: {
    globals: true,
    environment: 'node',
  },
})
```

```ts
// utils.test.ts
import { describe, it, expect } from 'vitest'
import { add } from './utils'

describe('add', () => {
  it('should add two numbers', () => {
    expect(add(1, 2)).toBe(3)
  })
})
```

## 4. Jest 与 Vitest 对比

| 特性         | Vitest             | Jest         |
| ------------ | ------------------ | ------------ |
| 与 Vite 集成 | 原生集成，共享配置 | 需要额外配置 |
| TypeScript   | 原生支持（Oxc）    | 需要 ts-jest |
| 速度         | 极快               | 较慢         |
| API 兼容     | 兼容 Jest API      | -            |
| ESM 支持     | 原生支持           | 实验性支持   |
| 迁移成本     | 从 Jest 迁移成本低 | -            |

## 5. 测试环境配置

- Vitest 支持多种测试环境：

```ts
// vitest.config.ts
export default defineConfig({
  test: {
    environment: 'jsdom', // 或 'happy-dom'、'node'
    environmentOptions: {
      jsdom: { url: 'http://localhost/' },
    },
  },
})
```

- 也可以在文件中指定环境：

```ts
// @vitest-environment jsdom
import { describe, it, expect } from 'vitest'
```

## 6. Mock 模块

- Vitest 内置了 Mock 功能：

```ts
import { vi, describe, it, expect } from 'vitest'

// Mock 模块
vi.mock('./api', () => ({
  getUsers: vi.fn().mockResolvedValue([{ id: 1, name: 'Alice' }]),
}))

// Mock 函数
const fn = vi.fn()
fn(1, 2)
expect(fn).toHaveBeenCalledWith(1, 2)
```

## 7. 覆盖率统计

- 使用 `@vitest/coverage-v8` 统计代码覆盖率：

```bash
npm install -D @vitest/coverage-v8
```

```ts
// vitest.config.ts
export default defineConfig({
  test: {
    coverage: {
      provider: 'v8',
      reporter: ['text', 'json', 'html'],
      include: ['src/**/*.{ts,vue}'],
      exclude: ['src/**/*.test.ts', 'src/**/*.d.ts'],
    },
  },
})
```

```bash
npx vitest run --coverage
```
