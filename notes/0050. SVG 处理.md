## 1. 本节内容

- 了解 Vite 中 SVG 的多种使用方式
- 掌握 SVG 作为图片、源码、组件的导入方式
- 了解 SVG Sprite 的使用方案

## 2. 评价

- SVG 在前端项目中使用广泛（图标、插画、数据可视化等），理解不同处理方式很重要
- 大型项目推荐使用 SVG 组件化方案（如 `vite-plugin-svg-icons`），提升开发体验

## 3. SVG 作为图片

- 最简单的方式：像普通图片一样导入 SVG 的 URL

```ts
import logoUrl from './logo.svg'
// logoUrl 为带哈希的 URL 字符串

document.getElementById('logo').src = logoUrl
```

```html
<img src="./logo.svg" />
```

- SVG 作为图片时：
  - 无法通过 CSS 控制内部颜色（如 `fill`、`stroke`）
  - 无法响应 CSS 的 `:hover` 等伪类
  - 适合不需要交互和样式控制的场景（如 Logo、插画）

## 4. SVG 作为源码

- 使用 `?raw` 后缀获取 SVG 的 XML 字符串：

```ts
import svgString from './icon.svg?raw'

// 直接插入 DOM
document.getElementById('app').innerHTML = svgString
```

- 插入后 SVG 成为 DOM 的一部分，可以通过 CSS 控制颜色和样式：

```css
.icon svg {
  fill: currentColor;
  width: 24px;
  height: 24px;
}
```

## 5. SVG 组件化

- 使用 `vite-plugin-svg-icons` 或 `vite-svg-loader` 等插件将 SVG 转为 Vue/React 组件：

```ts
// vite-svg-loader 示例
import IconVue from './icons/vue.svg?component'

// 使用方式（Vue）
// <IconVue class="icon" />
```

- 优势：
  - SVG 作为组件使用，支持 props 传递颜色、大小等
  - 可以利用框架的生命周期管理 SVG
  - 支持 TypeScript 类型提示

- 常用插件：
  - `vite-svg-loader`：将 SVG 转为 Vue/React 组件
  - `vite-plugin-svg-icons`：基于 SVG Sprite 的图标方案
  - `unplugin-icons`：自动从图标库（如 Iconify）导入 SVG 图标

## 6. SVG Sprite

- SVG Sprite 是将多个 SVG 图标合并为一个文件的技术，减少 HTTP 请求数
- 使用 `vite-plugin-svg-icons` 实现：

```ts
// vite.config.ts
import { createSvgIconsPlugin } from 'vite-plugin-svg-icons'

export default defineConfig({
  plugins: [
    createSvgIconsPlugin({
      iconDirs: [resolve(__dirname, 'src/icons')],
      symbolId: 'icon-[name]',
    }),
  ],
})
```

```ts
// main.ts
import 'virtual:svg-icons-register'
```

```html
<!-- 使用方式 -->
<svg>
  <use href="#icon-vue" />
</svg>
```

- 优势：
  - 所有图标合并为一个 SVG Sprite 文件，只需一次 HTTP 请求
  - 可以通过 CSS 控制颜色和大小
  - 适合大量图标的项目（如后台管理系统的图标集）
