## 1. 本节内容

- 了解 Vite 生产构建的源码流程
- 理解配置解析、插件注入、Rollup/Rolldown 调用和产物生成

## 2. 评价

- 构建流程比开发流程简单，核心是调用 Rollup/Rolldown 打包

## 3. 配置解析

- 构建流程的第一步：解析和合并配置
- 调用 `resolveConfig` 获取最终配置
- 处理 `build.lib`、`build.rollupOptions` 等构建相关配置

## 4. 插件注入

- Vite 在构建时注入一系列内置插件：
  - 依赖预构建插件
  - CSS 处理插件
  - 静态资源处理插件
  - HTML 处理插件
  - 代码压缩插件
- 用户插件与内置插件按 `enforce` 顺序合并

## 5. Rollup / Rolldown 调用

- 将合并后的配置和插件传递给 Rollup（或 Rolldown）
- 调用 `rollup.rollup()` 执行打包
- Rollup 依次执行：`buildStart` → `resolveId` → `load` → `transform` → `generateBundle`

## 6. 产物生成

- Rollup 生成最终的产物文件：
  - JS chunk（入口 chunk、动态 chunk、共享 chunk）
  - CSS 文件
  - 静态资源
- Vite 对产物进行后处理：
  - 代码压缩（Oxc）
  - CSS 压缩（Lightning CSS/PostCSS）
  - 资源哈希命名

## 7. Manifest 生成

- 如果开启了 `build.manifest`，生成 `manifest.json`
- 如果开启了 `build.ssrManifest`，生成 `ssr-manifest.json`
- 记录模块到产物文件的映射关系
