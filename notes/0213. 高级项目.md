## 1. 本节内容

- 了解 Vite 的高级应用场景项目
- 掌握 SSR、组件库、Monorepo、微前端、PWA 的实践

## 2. 评价

- 高级项目适合需要深入掌握 Vite 的开发者
- 这些场景在企业级项目中非常常见

## 3. Vite SSR 项目

- 使用 Vite 构建 SSR 应用
- 学习目标：
  - 服务端入口和客户端入口
  - 数据预取和状态序列化
  - Hydration 和同构渲染
  - 生产部署（Node.js / Docker）

## 4. Vite 组件库项目

- 使用 Vite 库模式开发 UI 组件库
- 学习目标：
  - 库模式配置（`build.lib`）
  - 外部依赖和 peerDependencies
  - 类型声明生成（`vite-plugin-dts`）
  - 按需引入和 Tree Shaking
  - 发布到 npm

## 5. Vite Monorepo 多包项目

- 使用 pnpm workspace + Turborepo 管理多包项目
- 学习目标：
  - workspace 配置
  - 共享组件库和工具库
  - 依赖去重（`resolve.dedupe`）
  - 统一构建和发布

## 6. Vite 微前端项目

- 使用 Module Federation 或 qiankun 实现微前端
- 学习目标：
  - 主应用和子应用的配置
  - 远程模块加载
  - 共享依赖
  - 样式隔离和 JS 沙箱

## 7. Vite PWA 项目

- 使用 `vite-plugin-pwa` 构建 PWA 应用
- 学习目标：
  - Service Worker 配置
  - 离线缓存策略
  - Manifest 配置
  - 安装到桌面
