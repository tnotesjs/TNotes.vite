## 1. 本节内容

- 了解 Tailwind CSS 与 Vite 的集成方式
- 掌握安装、配置和内容扫描的设置
- 理解 Tailwind CSS 的按需生成机制

## 2. 评价

- Tailwind CSS 是目前最流行的原子化 CSS 框架，与 Vite 集成良好
- Vite 官方 `create-vite` 脚手架不包含 Tailwind CSS 选项，Tailwind CSS 选项存在于 `create-vue`（Vue 专用脚手架）中
- Tailwind CSS v4 大幅简化了配置，与 Vite 的集成更加紧密

## 3. 安装 Tailwind CSS

- Tailwind CSS v4（推荐）：

```bash
npm install -D tailwindcss @tailwindcss/vite
```

- 在 `vite.config.ts` 中添加插件：

```ts
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
  plugins: [tailwindcss()],
})
```

- 在 CSS 入口文件中引入：

```css
@import 'tailwindcss';
```

- Tailwind CSS v3（旧版）：

```bash
npm install -D tailwindcss postcss autoprefixer
npx tailwindcss init -p
```

## 4. 配置内容扫描

- Tailwind CSS v4 不再需要手动配置内容扫描，自动检测项目中的类名
- Tailwind CSS v3 需要在 `tailwind.config.js` 中指定扫描路径：

```js
/** @type {import('tailwindcss').Config} */
export default {
  content: ['./index.html', './src/**/*.{vue,js,ts,jsx,tsx}'],
  theme: {
    extend: {},
  },
  plugins: [],
}
```

- `content` 配置决定了 Tailwind 会扫描哪些文件来生成样式
- 路径不正确会导致样式丢失（类名未被检测到）

## 5. 与 Vite 集成

- Tailwind CSS v4 通过 `@tailwindcss/vite` 插件直接集成，无需 PostCSS 配置
- Vite + Tailwind 的优势：
  - 开发时样式即时更新（HMR）
  - 构建时自动移除未使用的样式（Tree Shaking）
  - 零配置的 PostCSS 集成
- 在 Vue SFC 中使用：

```vue
<template>
  <div class="bg-blue-500 text-white p-4 rounded-lg">Hello Tailwind!</div>
</template>
```

## 6. 按需生成样式

- Tailwind CSS 只会生成项目中实际使用到的样式类
- 工作原理：
  1. 扫描 `content` 配置中指定的所有文件
  2. 提取所有 Tailwind 类名（如 `bg-blue-500`、`text-white`）
  3. 只为这些类名生成对应的 CSS 规则
  4. 未使用的类名不会出现在最终 CSS 中
- 效果：完整的 Tailwind CSS 有数 MB，按需生成后通常只有几十 KB
- 注意事项：
  - 动态拼接的类名（如 `` `bg-${color}-500` ``）可能无法被检测到
  - 应使用完整的类名：`bg-blue-500 bg-red-500`，或使用 safelist 配置
