## 1. 本节内容

- 了解前后端分离架构中 Vite 的配置方式
- 掌握 API 代理、CORS、多环境配置的实践

## 2. 评价

- 前后端分离是现代 Web 开发的主流架构
- Vite 的 `server.proxy` 是开发环境中解决跨域的最佳方案

## 3. 独立开发

- 前端和后端独立开发、独立部署
- 开发环境：前端 `localhost:5173`，后端 `localhost:8080`
- 通过 API 文档（Swagger/OpenAPI）约定接口格式

## 4. API 代理

- 使用 `server.proxy` 将 API 请求代理到后端：

```ts
export default defineConfig({
  server: {
    proxy: {
      '/api': {
        target: 'http://localhost:8080',
        changeOrigin: true,
        rewrite: (path) => path.replace(/^\/api/, ''),
      },
    },
  },
})
```

## 5. CORS

- 生产环境由后端或 Nginx 配置 CORS
- 开发环境使用代理避免跨域，无需额外 CORS 配置

## 6. 多环境配置

- 使用 `.env` 文件配置不同环境的 API 地址：

```
# .env.development
VITE_API_BASE_URL=http://localhost:8080

# .env.production
VITE_API_BASE_URL=https://api.example.com
```
