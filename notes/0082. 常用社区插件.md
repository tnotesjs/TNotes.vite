## 1. 本节内容

- 了解 Vite 生态中常用的社区插件
- 掌握各类插件的用途和选择建议

## 2. 评价

- Vite 社区生态活跃，大部分常见需求都有对应的插件
- 选择插件时注意查看维护状态和 Vite 版本兼容性

## 3. 自动导入插件

- `unplugin-auto-import`：自动导入 API，无需手动 `import`

```ts
import AutoImport from 'unplugin-auto-import/vite'

export default defineConfig({
  plugins: [
    AutoImport({
      imports: ['vue', 'vue-router', 'pinia'],
      dts: 'src/auto-imports.d.ts',
    }),
  ],
})
```

- 效果：`ref`、`computed`、`useRouter` 等 API 无需导入即可使用

## 4. 组件自动注册插件

- `unplugin-vue-components`：Vue 组件自动导入和注册

```ts
import Components from 'unplugin-vue-components/vite'
import { ElementPlusResolver } from 'unplugin-vue-components/resolvers'

export default defineConfig({
  plugins: [
    Components({
      resolvers: [ElementPlusResolver()],
      dts: 'src/components.d.ts',
    }),
  ],
})
```

- 效果：组件无需手动 import 和注册，直接在模板中使用

## 5. SVG 插件

- `vite-plugin-svg-icons`：SVG Sprite 图标方案
- `vite-svg-loader`：将 SVG 转为 Vue/React 组件
- `unplugin-icons`：从 Iconify 图标库自动导入图标
- 详见 0050 节「SVG 处理」

## 6. Mock 插件

- `vite-plugin-mock`：基于 Mock.js 的数据 Mock 方案

```ts
import { viteMockServe } from 'vite-plugin-mock'

export default defineConfig({
  plugins: [
    viteMockServe({
      mockPath: 'mock',
      enable: true,
    }),
  ],
})
```

- 适用场景：前后端并行开发时，模拟后端 API 响应

## 7. PWA 插件

- `vite-plugin-pwa`：将项目构建为 PWA（渐进式 Web 应用）

```ts
import { VitePWA } from 'vite-plugin-pwa'

export default defineConfig({
  plugins: [
    VitePWA({
      registerType: 'autoUpdate',
      manifest: {
        name: 'My App',
        short_name: 'App',
      },
    }),
  ],
})
```

- 功能：Service Worker 注册、离线缓存、安装提示等

## 8. ESLint 插件

- `vite-plugin-eslint`：在开发时实时显示 ESLint 错误

```ts
import eslint from 'vite-plugin-eslint'

export default defineConfig({
  plugins: [eslint()],
})
```

- 注意：会影响开发服务器启动速度，建议只在需要时启用

## 9. Checker 插件

- `vite-plugin-checker`：在浏览器中显示类型检查和 ESLint 错误
- 支持 TypeScript、Vue TSC、ESLint、Stylelint 等
- 详见 0060 节「类型检查」

## 10. Compression 插件

- `vite-plugin-compression`：构建时生成 Gzip/Brotli 预压缩文件

```ts
import compression from 'vite-plugin-compression'

export default defineConfig({
  plugins: [
    compression({ algorithm: 'gzip' }),
    compression({ algorithm: 'brotliCompress', ext: '.br' }),
  ],
})
```

- 配合 Nginx 的 `gzip_static` / `brotli_static` 指令，直接返回预压缩文件

## 11. Inspect 插件

- `vite-plugin-inspect`：检查 Vite 插件的转换结果
- 提供 Web 界面查看每个模块经过了哪些插件的处理
- 是调试 Vite 插件的利器，详见 0087 节
