## 1. 本节内容

- 了解 Vite 项目中 ESLint 的配置方式
- 掌握 Flat Config 的使用和 Vue/React/TypeScript 的 ESLint 配置

## 2. 评价

- ESLint 是代码质量的基石，每个项目都应配置
- ESLint v9+ 使用 Flat Config 格式，新项目应优先采用

## 3. ESLint 配置

- 安装：

```bash
npm install -D eslint @eslint/js
```

- 基本配置（Flat Config）：

```ts
// eslint.config.js
import js from '@eslint/js'

export default [
  js.configs.recommended,
  {
    rules: {
      'no-console': 'warn',
      'no-unused-vars': 'error',
    },
  },
]
```

## 4. Flat Config

- ESLint v9+ 推荐的配置格式（`eslint.config.js`）
- 优势：
  - 使用 ESM 语法
  - 配置合并更直观
  - 不需要 `.eslintrc` 文件
- 支持条件配置和函数式配置

## 5. Vue ESLint

- Vue 项目的 ESLint 配置：

```bash
npm install -D eslint-plugin-vue vue-eslint-parser
```

```ts
// eslint.config.js
import pluginVue from 'eslint-plugin-vue'

export default [
  ...pluginVue.configs['flat/recommended'],
  {
    rules: {
      'vue/multi-word-component-names': 'off',
    },
  },
]
```

## 6. React ESLint

- React 项目的 ESLint 配置：

```bash
npm install -D eslint-plugin-react eslint-plugin-react-hooks
```

```ts
// eslint.config.js
import react from 'eslint-plugin-react'
import reactHooks from 'eslint-plugin-react-hooks'

export default [
  {
    plugins: { react, 'react-hooks': reactHooks },
    rules: {
      'react-hooks/rules-of-hooks': 'error',
      'react-hooks/exhaustive-deps': 'warn',
    },
  },
]
```

## 7. TypeScript ESLint

- TypeScript 的 ESLint 配置：

```bash
npm install -D @typescript-eslint/parser @typescript-eslint/eslint-plugin
```

```ts
// eslint.config.js
import tsPlugin from '@typescript-eslint/eslint-plugin'
import tsParser from '@typescript-eslint/parser'

export default [
  {
    files: ['**/*.ts', '**/*.tsx'],
    languageOptions: { parser: tsParser },
    plugins: { '@typescript-eslint': tsPlugin },
    rules: {
      '@typescript-eslint/no-unused-vars': 'error',
      '@typescript-eslint/no-explicit-any': 'warn',
    },
  },
]
```
