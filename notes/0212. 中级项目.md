## 1. 本节内容

- 了解适合有一定基础的开发者的中级项目
- 掌握路由、状态管理、CSS 框架的集成

## 2. 评价

- 中级项目覆盖了大部分实际开发场景，是提升技能的关键

## 3. Vite + Vue + Pinia + Router 后台管理系统

- 完整的后台管理系统项目
- 学习目标：
  - Vue Router 路由配置和懒加载
  - Pinia 状态管理和持久化
  - 路由守卫和权限控制
  - API 封装和请求拦截
  - Element Plus / Ant Design Vue 集成
  - 环境变量和多环境配置

## 4. Vite + React + Router + Zustand 管理系统

- React 版本的后台管理系统
- 学习目标：
  - React Router v6 路由配置
  - Zustand 状态管理
  - React.lazy 和 Suspense 懒加载
  - Ant Design 集成
  - SWC 编译器的优势

## 5. Vite + Tailwind CSS 官网项目

- 使用 Tailwind CSS 构建企业官网
- 学习目标：
  - Tailwind CSS 与 Vite 的集成
  - 响应式设计
  - 暗黑模式
  - 静态资源优化
  - SEO 优化（meta 标签、结构化数据）
